# corporate_llm_chat_configs

Здесь находятся конфигурации для проекта корпоративного LLM-чата.

Репозиторий содержит централизованные конфигурации микросервисов системы:
API-шлюза (`gateway.yml`), сервиса чата (`chat-service.yml`),
сервиса проектов (`project-service.yml`) и сервиса пользователей
(`user-service.yml`). Конфигурации задают параметры маршрутизации,
подключения к сервисам и документации API (springdoc).
